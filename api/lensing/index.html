    kino.lensing¶

    Reduced-shear transformation of the image plane — applied jointly to the surface brightness and the velocity field. See Conventions for the shear/ellipticity sign conventions this module enforces.

    Reduced-shear transformation of the image plane.

    Applies the shear jointly to the surface brightness and the velocity field. Convention: reduced shear g = g1 + i*g2; ellipticity/distortion eps = (a-b)/(a+b). See CLAUDE.md before changing any sign or convention, and kino.lensing.shear's module docstring for the full derivation of the matrix and ellipticity-composition conventions.

    LensedScene(galaxy: object, g1: float, g2: float) dataclass ¶

    A galaxy observed through reduced shear (g1, g2).

    Wraps any object exposing surface_brightness(x, y), vlos(x, y), velocity_dispersion(x, y), x0, y0 (e.g. a :class:kino.galaxy.DiscGalaxy) and re-evaluates it at the delensed coordinate for each observed sky position, per kino.lensing.shear's beta = A @ theta convention -- both the surface brightness and the velocity field go through the identical spatial remapping (see CLAUDE.md: "Shear applied to velocity, not just image"). The shear is centred on the wrapped galaxy's own centroid (x0, y0), i.e. the galaxy is assumed to be its own local lens centre (KINO does not model convergence/magnification or a separate external lens position).

    photometric_ellipticity: tuple[float, float] property ¶

    Analytic (magnitude, PA-East-of-North-degrees) of the lensed image.

    Requires the wrapped galaxy to expose ellipticity (magnitude) and pa (degrees, East of North). Converts to/from kino.lensing.shear's standard-math-angle phase convention (phi = 90deg - pa, see that module's docstring), applies :func:kino.lensing.shear.shear_ellipticity, and converts back.

    kino.lensing.shear ¶

    Reduced-shear coordinate transform and its effect on ellipticity.

    Weak-lensing convention (Bartelmann & Schneider 2001; kappa=0, pure shear -- KINO does not model convergence as a free parameter). Pure shear alone still magnifies (see :func:magnification): with kappa=0, reduced shear equals shear exactly, but det(A) = 1 - |g|**2 != 1, so even an unconverged lens changes the observed solid angle -- and therefore total flux -- of the source. The lens Jacobian A = d(beta)/d(theta) maps an observed sky position theta to the source-plane position beta it came from::

    A = [[1 - g1,   -g2  ],
     [  -g2,   1 + g1]]
beta = A @ theta

    This is the standard ray-tracing direction: to render what an intrinsic (source-plane) model looks like once lensed, evaluate the source model at beta = A @ theta for each observed pixel theta (see kino.lensing.scene.LensedScene).

    Ellipticity convention

    KINO's complex ellipticity is eps = eps1 + i*eps2, with magnitude eps = (a-b)/(a+b) (CLAUDE.md) and phase 2*phi, phi the position angle measured the standard math way, counter-clockwise from the +x (East) axis -- not directly KINO's own pa (East of North), which runs the opposite sense from North: phi = 90 deg - pa. This module works in (eps1, eps2) / phi throughout; convert to/from kino.galaxy's pa explicitly (see kino.lensing.scene.photometric_ellipticity for a worked example) -- do not assume eps1 = eps*cos(2*pa) directly, that drops the 90-degree offset and comes out with the wrong sign.

    For a circular source (eps=0), reduced shear g = g1 + i*g2 produces eps_obs = g exactly -- this is what fixes the sign/orientation of A above (elongation from positive g1 alone is along the +x axis, i.e. phi=0), and is pinned by tests/lensing/test_shear.py::test_circular_source_ellipticity_equals_g.

    For a general intrinsic ellipticity, the composition follows the standard Mobius law (Seitz & Schneider 1997): eps_obs = (eps_int + g) / (1 + conj(g) * eps_int). Note this is not well-approximated by the naive sum eps_int + g except when eps_int is small: expanding in g, eps_obs = eps_int + g - eps_int**2 * conj(g) + O(g**2) -- the responsivity term -eps_int**2 * conj(g) is first order in g too and dominates the naive sum's error at small g whenever eps_int != 0 (see tests/lensing/test_shear.py::test_small_shear_linearisation).

    def shear_matrix(g1: float, g2: float) -> np.ndarray:
    """The lens Jacobian ``A`` such that ``beta = A @ theta`` (see module docstring)."""
    if g1**2 + g2**2 >= 1.0:
        raise ValueError(f"|g| must be < 1 (reduced shear), got g1={g1}, g2={g2}")
    return np.array([[1.0 - g1, -g2], [-g2, 1.0 + g1]])

    def shear_ellipticity(eps: complex, g1: float, g2: float) -> complex:
    """Apply reduced shear ``(g1, g2)`` to intrinsic complex ellipticity ``eps``."""
    g = complex(g1, g2)
    return (eps + g) / (1.0 + np.conj(g) * eps)

    def unshear_ellipticity(eps_obs: complex, g1: float, g2: float) -> complex:
    """Inverse of :func:`shear_ellipticity`: recover the intrinsic ``eps``."""
    g = complex(g1, g2)
    return (eps_obs - g) / (1.0 - np.conj(g) * eps_obs)

    magnification(g1: float, g2: float) -> float ¶

    Flux magnification mu = 1 / det(A) = 1 / (1 - g1**2 - g2**2).

    KINO's forward model conserves surface brightness under lensing (LensedScene just evaluates the source at the delensed coordinate, with no extra factor) -- magnification of the total flux integrated over a fixed observed area emerges automatically from that coordinate change of variables, exactly as it should (Liouville's theorem). Since det(A) = 1 - |g|**2 < 1 for any nonzero reduced shear, mu > 1 always -- pure shear alone magnifies, with no convergence needed. This matters for anything that uses observed flux as if it were the true (unlensed) flux, e.g. an uncorrected Tully-Fisher luminosity.

    def magnification(g1: float, g2: float) -> float:
    """Flux magnification ``mu = 1 / det(A) = 1 / (1 - g1**2 - g2**2)``.

    KINO's forward model conserves *surface brightness* under lensing
    (``LensedScene`` just evaluates the source at the delensed coordinate,
    with no extra factor) -- magnification of the *total* flux integrated
    over a fixed observed area emerges automatically from that coordinate
    change of variables, exactly as it should (Liouville's theorem). Since
    ``det(A) = 1 - |g|**2 < 1`` for any nonzero reduced shear, ``mu > 1``
    always -- pure shear alone magnifies, with no convergence needed. This
    matters for anything that uses observed flux as if it were the true
    (unlensed) flux, e.g. an uncorrected Tully-Fisher luminosity.
    """
    return 1.0 / (1.0 - g1**2 - g2**2)

    kino.lensing.moments ¶

    Unweighted flux-moment shape measurement, for validating/visualizing shear.

    Not a science-grade shape-measurement pipeline (no PSF correction, no weight function to suppress profile-wing noise) -- just enough to confirm a rendered, sheared image has the ellipticity kino.lensing.shear predicts analytically, and to draw the ellipse/axis overlays used in demo plots. Returns ellipticity in the same (eps1, eps2) convention as kino.lensing.shear (standard math-angle phase, see that module's docstring) -- not directly in kino.galaxy's East-of-North pa.

    def measure_moments(image: np.ndarray, x: np.ndarray, y: np.ndarray):
    """Flux-weighted centroid and second moments of ``image`` sampled at ``(x, y)``.

    Returns ``(xbar, ybar, qxx, qyy, qxy)``.
    """
    flux = np.asarray(image, dtype=float)
    x = np.asarray(x, dtype=float)
    y = np.asarray(y, dtype=float)
    total = flux.sum()
    xbar = (flux * x).sum() / total
    ybar = (flux * y).sum() / total
    dx = x - xbar
    dy = y - ybar
    qxx = (flux * dx**2).sum() / total
    qyy = (flux * dy**2).sum() / total
    qxy = (flux * dx * dy).sum() / total
    return xbar, ybar, qxx, qyy, qxy

    def measure_ellipticity(image: np.ndarray, x: np.ndarray, y: np.ndarray):
    """Centroid, complex ellipticity, and semi-axes of ``image`` at ``(x, y)``.

    Returns ``(xbar, ybar, eps1, eps2, a, b)``, with ``eps = eps1 + i*eps2``
    in ``kino.lensing.shear``'s standard-math-angle convention.
    """
    xbar, ybar, qxx, qyy, qxy = measure_moments(image, x, y)
    trace_half = 0.5 * (qxx + qyy)
    diff_half = 0.5 * (qxx - qyy)
    radius = np.hypot(diff_half, qxy)
    a = np.sqrt(trace_half + radius)
    b = np.sqrt(max(trace_half - radius, 0.0))
    eps_mag = (a - b) / (a + b)
    phi = 0.5 * np.arctan2(2.0 * qxy, qxx - qyy)
    eps1 = eps_mag * np.cos(2.0 * phi)
    eps2 = eps_mag * np.sin(2.0 * phi)
    return xbar, ybar, eps1, eps2, a, b
