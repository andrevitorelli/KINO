    kino.inference¶

    Likelihoods, priors, and a nautilus-backed sampler wrapper for recovering the (g1, g2) posterior. See Running inference for the full worked pattern.

    Shear inference.

    Likelihoods, priors, and a sampler wrapper behind a common API, used to recover the (g1, g2) posterior from mock or real data. nautilus (neural-network-boosted importance nested sampling) is kino's sole sampler -- see CLAUDE.md's "Language / stack" convention.

    IFUCubeLikelihood(ifu: IFU, line_wavelength: u.Quantity, data: Datacube, fixed_galaxy_params: dict = dict(), fixed_line_flux: u.Quantity | None = None, line_flux_unit: u.UnitBase | None = None) dataclass ¶

    Voxel-level Gaussian log-likelihood of an IFU cube.

    log L = -1/2 sum[(d - m)^2 / v + ln v] over every voxel.

    Each trial parameter set is forward-modelled through the fixed ifu into the expected cube m (sky + dark baseline included) and compared with the data cube voxel by voxel, with v = m + read noise^2 the expected variance (Poisson source + sky + dark plus read noise, Gaussian-approximated). Nothing is reduced to moments first, so -- unlike :class:IFUMomentLikelihood -- there is no estimator noise bias: on many noise realisations the maximum-likelihood shear was unbiased (to ~1e-4) and its scatter matched the Cramer-Rao bound (:func:kino.analysis.fisher.shear_fisher, estimator="cube") at every S/N tested, from per-spaxel S/N ~ 5 to ~100. It also uses the flux image and the line wings that the moment maps discard.

    Parameters are as for :class:IFUMomentLikelihood: g1/g2/line_flux handled here, any other free parameter a DiscGalaxy field.

    Voxel-level Gaussian log-likelihood of a slit spectrograph's dispersed spectrum.

    The :class:SlitSpectrograph analogue of :class:IFUCubeLikelihood: every trial parameter set is forward-modelled through the fixed slit (the companion broadband image is discarded -- only SlitObservation.spectrum enters the fit) and compared voxel by voxel with the same Gaussian likelihood, so slit losses (a source wider than the slit, or a misaligned slit_pa/slit_offset) are inside the model exactly as they are inside the data, rather than a bias.

    def summary(self) -> dict[str, tuple[float, float, float]]:
    """``{name: (median, -1sigma, +1sigma)}`` from the 16/50/84th percentiles."""
    out = {}
    for name in self.param_names:
        lo, med, hi = np.percentile(self.samples[name], [16.0, 50.0, 84.0])
        out[name] = (float(med), float(med - lo), float(hi - med))
    return out

    def build_prior(free_params: dict) -> Prior:
    """Build a ``nautilus.Prior`` from ``{name: dist}``.

    ``dist`` is either a ``(low, high)`` tuple (uniform) or any object with
    ``.ppf``/``.rvs`` (e.g. a ``scipy.stats`` frozen distribution, or
    :func:`tully_fisher_prior`'s return value) -- exactly what
    ``nautilus.Prior.add_parameter(dist=...)`` accepts.
    """
    prior = Prior()
    for name, dist in free_params.items():
        prior.add_parameter(name, dist=dist)
    return prior

    def tully_fisher_prior(
    flux: float,
    *,
    v0: float,
    flux0: float,
    alpha: float = TOY_TF_ALPHA,
    scatter_dex: float = 0.1,
) -> rv_continuous:
    """A log-normal ``scipy.stats`` distribution for ``v_flat``, centred on
    the toy Tully-Fisher relation's prediction at ``flux``, with
    ``scatter_dex`` scatter in :math:`\\log_{10} v_{\\rm flat}`.

    Pass the result as a parameter's ``dist`` in :func:`build_prior` (or
    directly to ``nautilus.Prior.add_parameter``).
    """
    from scipy.stats import norm

    v_center = tully_fisher_velocity(flux, v0=v0, flux0=flux0, alpha=alpha)
    log_v_center = np.log10(v_center)

    class _LogNormalV(rv_continuous):
        def _ppf(self, q):
            return 10.0 ** norm.ppf(q, loc=log_v_center, scale=scatter_dex)

        def _cdf(self, x):
            with np.errstate(divide="ignore"):
                return norm.cdf(np.log10(x), loc=log_v_center, scale=scatter_dex)

    return _LogNormalV(a=0.0, name="toy_tully_fisher_v_flat")

    def tully_fisher_velocity(
    flux: float, *, v0: float, flux0: float, alpha: float = TOY_TF_ALPHA
) -> float:
    """Toy Tully-Fisher relation: ``v = v0 * (flux / flux0) ** (1 / alpha)``.

    Not a calibrated relation -- see the module docstring.
    """
    return v0 * (flux / flux0) ** (1.0 / alpha)

    def fit_shear(
    prior,
    likelihood,
    *,
    n_live: int = 2000,
    seed: int | None = None,
    verbose: bool = False,
    n_eff: float = 10000,
    **sampler_kwargs,
) -> Posterior:
    """Run ``nautilus`` nested sampling and return a :class:`Posterior`.

    Parameters
    ----------
    prior : nautilus.Prior
        E.g. from :func:`kino.inference.priors.build_prior`.
    likelihood : Callable[[dict], float]
        E.g. an :class:`~kino.inference.likelihood.IFUMomentLikelihood`.
    n_live, seed, verbose : optional
        Forwarded to ``nautilus.Sampler``/``.run()``.
    n_eff : float, optional
        Target effective sample size, forwarded to ``.run()`` -- the usual
        knob for trading runtime against posterior sample count/evidence
        precision (lower for a fast smoke test, higher for a real run).
    **sampler_kwargs
        Forwarded to ``nautilus.Sampler`` (e.g. ``pool`` for
        multiprocessing).

    Returns
    -------
    Posterior
    """
    sampler = Sampler(prior, likelihood, n_live=n_live, pass_dict=True, seed=seed, **sampler_kwargs)
    sampler.run(verbose=verbose, n_eff=n_eff)
    points, _log_w, _log_l = sampler.posterior(return_as_dict=True, equal_weight=True)
    return Posterior(samples=points, log_z=float(sampler.log_z), param_names=list(points.keys()))
